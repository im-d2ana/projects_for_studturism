# 💞 LoveFam

**Закрытое семейное пространство, которое само собирает фотоальбомы и рисует семейное древо.**

Фотографии, праздники, родственники и списки желаний обычно живут в десятке разных приложений. LoveFam собирает всё в одном месте — только для вашей семьи, без соцсетей и посторонних глаз.

## ✨ Что умеет

- 📸 **Автоальбомы** — загрузите фото, и LoveFam сам разложит их по событиям и датам и соберёт готовые развороты. Никакой ручной вёрстки.
- 🌳 **Семейное древо** — родители, дети, супруги, братья и сёстры по поколениям, с фото и датами жизни.
- 📅 **Семейный календарь** — дни рождения, поездки и праздники; фото прикрепляются прямо к событию.
- 🎁 **Виш-листы** — общие списки желаний с ценой, приоритетом и статусом «куплено».
- 📊 **Аналитика** — сколько событий было в каждом месяце, какие желания исполнены, тепловая карта семейной активности.
- 🔒 **Приватность** — у каждого события, фото и желания свой уровень доступа: только я / ближний круг / всё древо.

## 🚧 Статус

Проект на стадии проектирования: готовы анализ предметной области, архитектура, база данных и макеты интерфейсов. Прототип — в разработке.
