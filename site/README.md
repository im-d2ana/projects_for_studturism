# Practicum MUI

**Живая демонстрация проекта:** [https://im-d2ana.github.io/site/#/](https://im-d2ana.github.io/site/#/)

Учебный проект на React с использованием Material UI, Redux и DnD-библиотек. 
Приложение развернуто на GitHub Pages.

## 🚀 Стек технологий

- **React** (v19)
- **TypeScript**
- **Material UI (MUI)** + Data Grid + Charts
- **Redux Toolkit** (управление состоянием)
- **React Router DOM** (v7, хэш-роутинг для GitHub Pages)
- **@dnd-kit** (drag-and-drop функционал)
- **Create React App** (`react-scripts`)
